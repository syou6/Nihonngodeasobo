# Full Test Suite

Run all tests for the AI Voice Journal app. This includes unit tests (Vitest) and E2E tests (Playwright).

## Steps

1. Run TypeScript type check: `npx tsc --noEmit`
2. Run unit tests with coverage: `npm run test`
3. Run E2E tests: `npm run test:e2e`
4. Report results summary

If any test fails, analyze the failure and suggest fixes.
