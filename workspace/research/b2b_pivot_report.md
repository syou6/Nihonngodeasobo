# 「日本語であそぼ」B2Bピボット調査レポート

作成日: 2026年3月7日

---

## エグゼクティブサマリー

日本の企業向け英語研修市場（eラーニング含む）は2024年度約5,800億円規模で、そのうちeラーニングBtoB市場は1,173億円。日本の英語力はEF EPI 2024で世界92位（過去最低）に低下しており、企業のグローバル人材育成ニーズは高まる一方、既存サービスはAIスコア判定・進捗管理・家族・保護者連携の機能が弱い。「日本語であそぼ」の技術資産（Gemini AI、CEFR判定、ダッシュボード、ロールベース権限）はこの市場の課題に直結しており、3つの有力なB2Bピボット案が考えられる。

## 1. 企業向け英語研修市場

### 1-1. 市場規模

| 区分 | 規模 | 備考 |
|------|------|------|
| 企業研修全体 | 約5,800億円（2024年度） | 前年比増、コロナ前超え |
| eラーニングBtoB市場 | 1,173億円（2024年度） | 全体の約20.2% |
| 語学ビジネス全体 | 7,806〜7,906億円 | 個人+法人含む |
| 日本EdTech市場 | 約2.2兆円（148億ドル、2024年） | 2033年に768億ドル予測 |

出典: qualif.jp「2025年に向けた企業向けeラーニング市場の動向」

### 1-2. 企業が抱える課題

**英語力の深刻な低下**
- EF EPI 2024で日本は世界116カ国中92位（過去最低、前年87位からさらに後退）
- 平均スコア454点、世界トップのオランダ（636点）と182点差
- 採用時にTOEICスコアを要件・参考とする企業は73.6%

**研修の効果測定の困難さ**
- LMS機能が数年間進歩していない（qualif.jp調査）
- 「お手軽に流れすぎ」なコンテンツで学習効果が低下
- 管理部門が現場の英語力レベルを把握できない

**人材配置の非効率**
- 企業の技術部門が社員に期待するTOEIC平均: 560点
- 営業部門: 580点、海外部門: 705点
- スコアと実際のスピーキング力が乖離していることが多い

### 1-3. 既存サービスの料金

| サービス | 月額（1人あたり） | 特徴 |
|---------|----------------|------|
| スタディサプリENGLISH（法人） | 1,980円/月（年払い） | TOEIC対策特化、アプリベース |
| Bizmates | 13,500円 | ビジネス経験者講師 |
| ネイティブキャンプ法人 | 6,800円 | 回数無制限、130カ国講師 |
| PROGOS（AIスピーキングテスト） | 550円/受験 | CEFR判定、20分、2分で結果 |
| トライズ | 24,300円〜 | 年1,000時間、成果保証付き |
| ポリグロッツ | 13,620円 | AI個別最適化+プロ講師 |
| Versant（スピーキングテスト） | 5,500円/回（個人）、法人割引あり | ピアソン製、AI採点 |

**市場の料金感**: 本格的なBizmates/ベストティーチャー系は月1.3万〜2.4万円が主流。AIアプリ系（スタサプ等）は月2,000円前後。AIテスト単体（PROGOS）は550円/回という超低価格。

## 2. 学校・塾向けEdTech市場

### 2-1. 市場動向

| 指標 | データ |
|------|--------|
| 日本EdTech市場（2024年） | 約3,185億円（野村総研推計） |
| 成長率（2025〜2033） | 年率20%（IMARC Group） |
| 学校向けICT化 | GIGAスクール以降、1人1台端末普及 |

### 2-2. 学校向けSaaSの成功例と料金

**Classi（クラッシー）**
- 導入: 3,500校以上、累計210万人以上の生徒
- 料金: 生徒1人あたり3,600円/年（月額300円相当）
- 親会社: ソフトバンク、ベネッセ
- 機能: 学習管理、コミュニケーション、ポートフォリオ

**Studyplus for School（スタディプラス）**
- 2023年4月に無料プラン開始→フリーミアム戦略に転換
- 目標: 10,000校以上の導入
- 課題解決: 勉強時間の可視化、習慣化

**atama plus**
- 累計調達額: 約82億円（シリーズB時点）
- AI個別最適化学習、塾導入型
- 一般への公開料金なし（塾経由の導入）

**モノグサ（Monoxer）**
- 2,500以上の塾・予備校で利用（2020年時点）
- 「記憶のプラットフォーム」として出版社とアライアンス
- B2B SaaSからプラットフォームへの展開モデルを実証

**POPER（Comiru）**
- 塾向け生徒管理・保護者コミュニケーション・経理SaaS
- 東証グロース上場、前期比経常利益84.8%増

### 2-3. 英語教育デジタル化の特徴

- GIGAスクール端末の普及でクラウド型LMSの導入障壁が大幅低下
- 塾業界では「個別最適化」が最重要キーワード
- 保護者への進捗報告機能が差別化要因（Classi, POPER等で実証済み）
- AI採点・自動フィードバックへのニーズが急増

## 3. B2B SaaSの料金モデル成功パターン

### 3-1. 主要な課金モデル比較

| モデル | 説明 | 日本での成功例 | 向いている状況 |
|--------|------|--------------|----------------|
| SEAT課金（ユーザー数） | 1ユーザーあたり月額 | スタサプENGLISH（1,980円/人/月）、Classi（300円/人/月） | ユーザーが明確に特定できる |
| 組織/拠点課金 | 学校・支店単位での定額 | 多くのLMS（月4万〜） | 組織規模差が大きい |
| 受験/使用回数課金 | アクションごとの従量 | PROGOS（550円/受験） | 利用頻度が不規則な場合 |
| 成果報酬型 | スコア向上・達成率連動 | トライズ（保証制度付き） | 高価格帯サービス |
| フリーミアム | 無料+有料アップグレード | Studyplus for School | 普及優先フェーズ |

### 3-2. 日本B2B SaaSで重要な要素

- **請求書払い対応**: 日本企業は口座振替・請求書を強く好む
- **長期契約割引**: 6カ月・12カ月割引が当たり前（スタサプは6→12カ月で約40%割引）
- **無料トライアル**: 企業向けは1〜3カ月の試験導入が事実上必須
- **担当者アサイン**: 日本企業はCS（カスタマーサクセス）への期待が高い
- **ROI可視化**: 英語力スコア変化をダッシュボードで示すことが継続契約の鍵

## 4. 具体的なB2Bピボット案（3案）

---

### 案A: 「企業向け英語力リアルタイム診断・研修管理SaaS」

#### コンセプト

「日本語であそぼ」のCEFR自動判定・AI採点・ダッシュボード機能をそのまま法人向けに転用。従業員の英語スピーキング力をいつでも測定し、部署別・個人別の進捗を人事担当者がリアルタイムで管理できる「英語力可視化プラットフォーム」。

#### なぜ今この市場か

- PROGOSの成功（550円/回、1,000社以上）が市場の存在を証明
- Versantは高価（5,500円/回）でスキマあり
- 企業が求めるのは「テストだけ」でなく「継続学習と測定のセット」
- 既存の研修サービスは「AI採点+ダッシュボード」が弱い

#### 技術資産の活用

| 既存機能 | B2B転用 |
|---------|---------|
| Versant模擬試験（Part E/F） | 社員向けスピーキング模擬試験 |
| CEFR自動判定 | 英語力の国際指標での可視化 |
| 保護者/教師ダッシュボード | 人事担当者ダッシュボードに転用 |
| Gemini AIフィードバック | 個人別改善提案レポート生成 |
| ロールベース閲覧権限 | 部署長/人事/経営役員の権限分離 |

#### 想定顧客

- **プライマリー**: 従業員300〜3,000名規模の製造業・商社・IT企業
- **セカンダリー**: 外資系参入を検討している中堅企業、海外展開中の中小企業

#### 料金モデル

```
スターターパック（30名まで）: 月額49,800円
- スピーキング診断 月2回/人
- 人事ダッシュボード（部署別進捗、CEFR分布）
- AI個別フィードバックレポート

スタンダード（100名まで）: 月額99,800円
- スピーキング診断 月4回/人
- 全機能 + 目標設定・アラート機能
- 月次レポート自動生成

エンタープライズ（100名超）: 月額200,000円〜
- 人数に応じた従量課金
- SLA保証、専任CSサポート
```

**平均顧客単価（ACV）想定**: 年間120万〜240万円

#### TAM（市場規模）試算

- 日本の従業員300名以上企業: 約16,000社
- そのうち英語研修に予算をかけている企業（推定30%）: 4,800社
- 平均受注単価: 年間120万円
- **TAM**: 約576億円/年

PROGOS単体の年間売上（1,000社 × 推定100万円）≒100億円水準が市場規模の参考指標。

#### 競合優位性

- Versant（5,500円/回）と比べ定額で測り放題
- PROGOSと異なり「研修管理ダッシュボード」までセット
- AI採点（Gemini）+ CEFR判定を内製しているため原価が低い
- ロールベース権限管理で大企業の組織構造に対応済み

---

### 案B: 「英会話教室・塾向け生徒管理・AI採点SaaS」

#### コンセプト

日本全国に約20,000〜30,000教室ある英会話スクール・英語塾向けに、月謝管理・出席管理・生徒の英語力測定・保護者レポートを一括提供するAll-in-One SaaS。Classiの成功モデル（月300円/生徒）を英語特化・AI採点付きで実現。

#### なぜ今この市場か

- 英語塾はICT化が遅れており、Excelと電話が主流
- Classi（学校向け）は英語力測定（CEFR判定）がない
- POPERは経理・管理には強いが英語力測定がない
- AI採点で講師の採点コストを削減したい需要が高い

#### 技術資産の活用

| 既存機能 | B2B転用 |
|---------|---------|
| 家族関係管理（保護者-子ども） | 保護者-生徒の権限管理に直接転用 |
| 保護者ダッシュボード | 保護者向け月次レポートポータル |
| CEFR自動判定 | レベル分けの自動化 |
| Gemini AIフィードバック | 講師の採点負担削減 |
| Supabase RLS | マルチテナントデータ分離に転用 |
| PWA対応 | アプリ配布不要、導入コスト削減 |

#### 想定顧客

- **プライマリー**: 教室規模30〜300名の英会話スクール・英語塾
- **セカンダリー**: 英語に特化した学習塾チェーン（ECC、英会話イーオン等の地域フランチャイジー）

#### 料金モデル

```
ライトプラン（生徒50名まで）: 月額9,800円
- AI採点（月4回/生徒）
- 保護者レポート自動生成
- 出席・月謝管理

スタンダード（200名まで）: 月額24,800円
- 全機能 + CEFR判定レポート
- 保護者アプリ（PWA）

プロ（200名超）: 月額49,800円〜
- 複数教室管理（チェーン対応）
- 講師別パフォーマンス分析
```

**参考**: Classiは生徒1人300円/月。生徒150名の教室で月45,000円相当。
本サービスの「スタンダード」は24,800円で同規模に対応 → コスト競争力あり。

#### TAM試算

- 全国英会話教室・英語塾: 推定25,000〜35,000教室
- SaaS導入率（現状5%→目標30%）: 7,500〜10,000教室
- 平均単価: 月額2万円 × 12カ月 = 年24万円
- **TAM（30%普及時）**: 約180〜240億円/年

#### 競合優位性

- POPERは英語力測定がない
- Classiは塾向けの月謝・出席管理がない
- AI採点+CEFR判定+保護者ポータルのセットは市場にほぼ存在しない
- Supabase RLSによるマルチテナントが既に実装済み

### 案C: 「グローバル企業HR部門向け・採用英語力スクリーニングAPI/SaaS」

#### コンセプト

新卒・中途採用時の英語力スクリーニングをAPIで提供するB2B2Cモデル。採用管理システム（ATS）にAPI連携し、候補者がスマホでCEFR判定付きスピーキングテストを受験。AIが即時採点、採用担当者に自動レポートを送付。

#### なぜ今この市場か

- Amazonジャパンが採用でPROGOSを活用（参考事例）
- Versant（5,500円/回）は高く、大量スクリーニングに不向き
- PROGOSは550円/回だが、ATSとの連携機能が弱い
- 外資・グローバル日系企業は英語力の客観評価に強い需要

#### 技術資産の活用

| 既存機能 | B2B転用 |
|---------|---------|
| Versant模擬試験（Part E/F） | 採用向けスピーキングテストに転用 |
| CEFR自動判定 | 採用基準への自動マッピング |
| Gemini AI採点 | 低コストでのリアルタイム採点 |
| Supabase Edge Functions | API化（採用ATSとの連携） |
| サーキットブレーカー実装 | エンタープライズ向け安定性 |

#### 想定顧客

- **プライマリー**: 採用時に英語スクリーニングを行うグローバル企業HR部門（従業員1,000名以上）
- **セカンダリー**: 人材紹介会社・転職エージェント（候補者のスクリーニングツールとして）

#### 料金モデル

```
従量課金モデル:
- 受験1回あたり: 800円（法人割引後）
- 月100受験パック: 60,000円（600円/受験）
- 月500受験パック: 200,000円（400円/受験）

ATSプラットフォーム連携API:
- 初期接続費: 200,000円
- 月額API利用料: 30,000円 + 従量（受験ごと）
```

**参考比較**:
- Versant: 5,500円/回 → 本サービスは約85%安
- PROGOS: 550円/回 → 本サービスは同価格帯だがAPI連携付き

#### TAM試算

- 日本の年間新卒採用数: 約50万人（大卒）
- 英語力スクリーニングが必要な採用: 推定20%（10万人）
- 中途採用: 年間400万件のうち英語職種10%（40万件）
- 合計スクリーニング機会: 年間50万回
- 平均単価: 600円/回
- **TAM（採用スクリーニング）**: 約300億円/年
- さらに人材紹介会社経由のB2B2Cモデルで拡大可能

#### 競合優位性

- Versantより大幅に安価でATSネイティブ連携
- PROGOSにはAPI提供がなく（2025年時点）、連携競争力が低い
- 既存のサーキットブレーカー実装で大量アクセス耐性を証明済み
- 採用結果を匿名集計 → 業界別英語力ベンチマークデータという副産物

## 5. 3案の比較サマリー

| 評価軸 | 案A: 企業研修管理SaaS | 案B: 英語塾向けSaaS | 案C: 採用スクリーニングAPI |
|--------|---------------------|-------------------|--------------------------|
| TAM | 576億円 | 180〜240億円 | 300億円 |
| 既存機能の転用率 | 高（80%以上） | 高（90%以上） | 中（60%） |
| 初期営業コスト | 高（エンタープライズ） | 中（SMB） | 中〜高（HR部門） |
| 受注単価（年） | 120〜240万円 | 24〜60万円 | 10〜500万円 |
| 競合の強さ | 中（PROGOS等） | 低〜中（ニッチ空白あり） | 中（Versant等） |
| 開発追加工数 | 小〜中 | 小（ほぼ転用可） | 中（API化が必要） |
| 推奨度 | ★★★★☆ | ★★★★★ | ★★★☆☆ |

**最推奨: 案B（英語塾向けSaaS）**

理由:
1. 既存の「保護者-子ども-教師」の3者関係管理が直接転用可能
2. SMB顧客は稟議が短く、月謝制のため継続課金との相性が良い
3. PROGOSやVersantのような大手競合が参入していないニッチ市場
4. まず案Bで収益基盤を作り、案Aへのアップセルが狙える
