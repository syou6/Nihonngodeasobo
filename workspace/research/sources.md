# Sources - Japanese Pitch Accent Research

1. [GitHub - itsupera/onsei](https://github.com/itsupera/onsei) — Python pitch accent comparison tool using DTW + pitch detection. Accessed 2026-03-08.
2. [GitHub - shirakaba/pitch-accent](https://github.com/shirakaba/pitch-accent) — TypeScript library to predict pitch accent patterns. BSD/GPL licensed. Accessed 2026-03-08.
3. [GitHub - peterkhayes/pitchfinder](https://github.com/peterkhayes/pitchfinder) — JS pitch detection algorithms (YIN, McLeod, AMDF, Dynamic Wavelet). Accessed 2026-03-08.
4. [pitchy - npm](https://www.npmjs.com/package/pitchy) — McLeod Pitch Method in pure JS, real-time capable. Accessed 2026-03-08.
5. [GitHub - cwilso/PitchDetect](https://github.com/cwilso/PitchDetect) — Web Audio API autocorrelation pitch detection reference. Accessed 2026-03-08.
6. [Detecting pitch with Web Audio API + autocorrelation](https://alexanderell.is/posts/tuner/) — Full autocorrelation code walkthrough. Accessed 2026-03-08.
7. [GitHub - DJTB/hatsuon](https://github.com/DJTB/hatsuon) — npm library for Japanese pitch accent pattern utils. Accessed 2026-03-08.
8. [GitHub - IllDepence/SVG_pitch](https://github.com/IllDepence/SVG_pitch) — SVG visualization of pitch accent with Wadoku DB. Accessed 2026-03-08.
9. [GitHub - mifunetoshiro/kanjium](https://github.com/mifunetoshiro/kanjium) — 124,137-word pitch accent database (accents.txt). CC licensed. Accessed 2026-03-08.
10. [GitHub - crnhrv/nami](https://github.com/crnhrv/nami) — React pitch accent training game using Kanjium data. Accessed 2026-03-08.
11. [OJAD - Online Japanese Accent Dictionary](https://www.gavo.t.u-tokyo.ac.jp/ojad/eng/pages/home) — 9000+ noun database with pitch patterns, Suzuki-kun tool. Accessed 2026-03-08.
12. [Gemini API Audio Understanding](https://ai.google.dev/gemini-api/docs/audio) — Audio formats, inline base64, 20MB limit, 9.5hr max. Accessed 2026-03-08.
13. [Firebase AI Logic: Analyze Audio](https://firebase.google.com/docs/ai-logic/analyze-audio) — JS code example for inline base64 audio to Gemini. Accessed 2026-03-08.
14. [SpeechSuper API](https://www.speechsuper.com/) — Commercial API with Japanese pronunciation assessment. Accessed 2026-03-08.
15. [Azure Speech Pronunciation Assessment](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/how-to-pronunciation-assessment) — Prosody only for en-US locale. Accessed 2026-03-08.
16. [Japanese Pitch Accent - Wikipedia](https://en.wikipedia.org/wiki/Japanese_pitch_accent) — Definitive overview of pitch accent types. Accessed 2026-03-08.
17. [Migaku: Japanese Pitch Accent Patterns Guide](https://migaku.com/blog/japanese/japanese-pitch-accent) — Practical guide to four pattern types. Accessed 2026-03-08.
18. [olety/japanese-pitch-accent-resources](https://github.com/olety/japanese-pitch-accent-resources) — Consolidated list of pitch accent tools and data. Accessed 2026-03-08.
19. [AI-Powered Pronunciation Mistake Detection Using Gemini 1.5 Flash](https://www.academia.edu/152382290/AI_Powered_Pronunciation_Mistake_Detection_Using_Gemini_1_5_Flash_A_Training_Free_Approach) — Research paper. Accessed 2026-03-08.
